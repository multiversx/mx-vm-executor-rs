# EI — Environment Interface model

This module describes the **smart contract Environment Interface (EI)**: the set of VM hooks (imported functions) that a contract may call. It also records how that set changed over time.

The EI version is separate from the VM version, so the numbering is different. See `EIVersion` in [ei_version.rs](ei_version.rs) for what each version maps to (release, date).

The code was moved here from `mx-sdk-rs` (`framework/meta-lib/src/ei`), where `sc-meta` uses it to check contract imports. It now lives next to the executor, so the hook list and the VM hooks traits are kept in one place.

## Generated files

Files that start with `// Code generated by vmhooks generator. DO NOT EDIT.` come from the VM hooks generator in `mx-chain-vm-go`:

```
mx-chain-vm-go/vmhost/vmhooks/generate/cmd/eiGenMain.go
```

The generator reads the Go VM hook declarations. It writes its output to `vmhost/vmhooks/generate/cmd/output/` and can copy that output into this repo (see `wasm-vm-executor-rs-path.txt`). The same run produces `vm_hooks.rs`, `wasmer_imports.rs`, `opcode_cost.rs` and the other generated executor files, so all of them describe the same set of hooks.

Don't edit generated files by hand. Change the Go declarations and run the generator again.

`ei_1_3.rs` and `ei_1_4.rs` are generator snapshots taken when those versions were current. Nothing writes to them any more, and they must not change.

## Tests

`vm-executor/tests/ei_test.rs` checks that each version is the previous version plus its delta, with no duplicates.
